# Инструкция по развертыванию бота на сервере (VPS)

Чтобы бот работал 24/7 и не зависел от вашего ноутбука, его нужно перенести на виртуальный сервер (VPS).

---

## Шаг 1: Аренда сервера (VPS)

Вам подойдет самый дешевый тариф (1 CPU, 1-2 GB RAM, Ubuntu 22.04/24.04).

**Где арендовать (примеры):**
*   **Aeza.net** (РФ/Европа, от ~100₽/мес, принимают карты РФ)
*   **Timeweb Cloud** (РФ, от ~200₽/мес)
*   **FirstVDS** (РФ, от ~250₽/мес)

**При заказе выберите:**
*   OS: **Ubuntu 22.04** (или новее)
*   Локация: Любая (Москва/СПб для РФ быстрее, Европа — если нужен доступ к заблокированным ресурсам, но тогда нужен VPN для оплаты).

После оплаты вам на почту придет IP-адрес сервера, логин (`root`) и пароль.

---

## Шаг 2: Подключение к серверу

Вам понадобится программа **PuTTY** (или просто терминал Windows).

1.  Откройте PowerShell (или командную строку) на своем компьютере.
2.  Введите команду:
    ```powershell
    ssh root@ВАШ_IP_АДРЕС
    ```
    *(Например: `ssh root@192.168.1.1`)*
3.  На вопрос `Are you sure...` напишите `yes` и нажмите Enter.
4.  Введите пароль (он не будет отображаться при вводе) и нажмите Enter.

*Теперь вы внутри сервера!*

---

## Шаг 3: Подготовка сервера

Выполните эти команды по очереди (копируйте и вставляйте правой кнопкой мыши):

1.  **Обновите систему:**
    ```bash
    apt update && apt upgrade -y
    ```

2.  **Установите Python и pip:**
    ```bash
    apt install python3 python3-pip python3-venv git -y
    ```

---

## Шаг 4: Перенос файлов бота

Самый простой способ — через **FileZilla** (бесплатная программа).

1.  Скачайте и установите [FileZilla Client](https://filezilla-project.org/).
2.  Вверху введите:
    *   **Хост:** `sftp://ВАШ_IP_АДРЕС`
    *   **Имя пользователя:** `root`
    *   **Пароль:** Ваш пароль от сервера
    *   **Порт:** 22
3.  Нажмите "Быстрое соединение".
4.  Слева (ваш комп) найдите папку с ботом.
5.  Справа (сервер) создайте папку `bot` (ПКМ -> Создать каталог).
6.  Перетащите **все файлы** из папки бота (кроме `venv` и `__pycache__`) в папку `bot` на сервере.
    *   Обязательно перенесите: `src/`, `books/`, `data/`, `prompts/`, `.env`, `requirements.txt`, `run_telegram.py`.

---

## Шаг 5: Запуск бота на сервере

Вернитесь в терминал (где вы подключены по SSH).

1.  **Перейдите в папку бота:**
    ```bash
    cd bot
    ```

2.  **Создайте виртуальное окружение:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    # Используйте файл зависимостей в папке docs (включает langdetect)
    pip install -r docs/requirements.txt
    ```

4.  **Проверьте запуск (тестовый):**
    ```bash
    python3 run_telegram.py
    ```
    *Если бот запустился и работает — нажмите `Ctrl+C`, чтобы остановить.*

Дополнительные настройки и команды

- По умолчанию бот поддерживает английский и русский. Вы можете принудительно установить язык для пользователя командой `/lang en` или `/lang ru`.
- Пользователи могут локально задать вероятность того, что бот задаст уточняющий вопрос, командой `/askprob 0.2` (значение 0.0–1.0). `reset` сбрасывает локальную настройку.
- Пользователи могут прислать фото — бот попытается дать экзистенциальный анализ изображения.

Персистентные пользовательские настройки (язык, локальная вероятность) сохраняются в `data/user_prefs.json`.

## Шаг 6: Запуск в фоновом режиме (24/7)

Чтобы бот работал даже после закрытия терминала, используем `systemd`.

1.  **Создайте файл службы:**
    ```bash
    nano /etc/systemd/system/bot.service
    ```

2.  **Вставьте туда этот текст (ПКМ для вставки):**
    ```ini
    [Unit]
    Description=Existential Therapist Bot
    After=network.target

    [Service]
    User=root
    WorkingDirectory=/root/bot
    ExecStart=/root/bot/venv/bin/python3 /root/bot/run_telegram.py
    Restart=always
    RestartSec=10

    [Install]
    WantedBy=multi-user.target
    ```
    *(Нажмите `Ctrl+O`, `Enter` для сохранения, затем `Ctrl+X` для выхода)*

3.  **Запустите службу:**
    ```bash
    systemctl daemon-reload
    systemctl enable bot
    systemctl start bot
    ```

4.  **Проверьте статус:**
    ```bash
    systemctl status bot
    ```
    *Должно быть написано `active (running)` зеленым цветом.*

**Всё! Теперь бот работает на сервере. Можете закрывать терминал и выключать ноутбук.**

## Полезные команды

*   **Посмотреть логи бота:**
    ```bash
    journalctl -u bot -f
    ```
*   **Перезапустить бота:**
    ```bash
    systemctl restart bot
    ```
*   **Остановить бота:**
    ```bash
    systemctl stop bot
    ```
