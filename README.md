# Рой (Roi) — диалоговый ИИ Telegram version

Диалоговый ассистент для экзистенциальной терапии в традиции **Ирвина Ялома** и **Виктора Франкла**.
Помогает исследовать темы смысла, свободы, одиночества и конечности жизни.

> Диалоговый ассистент — не замена живому специалисту. Если вам тяжело или вы в кризисе — лучше, конечно, обратиться за профессиональной помощью.

## Возможности

- Диалог в духе экзистенциальной терапии (текст, голос, фото)
- RAG по книгам и датасету ассоциаций (Qdrant + sentence-transformers)
- Анализ ассоциаций (`/assoc`) и разбор ситуации (`/lysis`)* Русский и английский интерфейчс
*;нимок на плёнку (`/shoot`)
- Админ-команды, отзывы и т.д.

## Быстрый старт

### 1. Установка

```bash
git clone https://github.com/WhatAMistake/roi.git
cd roi

python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Конфигурация

```bash
# Windows
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

Минимально заполните`.env `по примеру .env.example:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCdef...
OPENAI_API_KEY=your-api-key
OPENAI_API_BASE=https://api.cometapi.com/v1
ADMIN_ID=your-telegram-id
```

Бот использует CometAPI через OpenAI-совместимый API. Для другого совместимого API проверьте поддержку выбранных моделей и параметров.
Для провайдеров из РФ см. `docs/RUSSIAN_API.md`.

Для терапевтических запросов укажите `OPENAI_MODEL`; `OPENAI_ANALYSIS_MODEL` необязателен и при отсутствии наследует основную модель. Явные `--model` и `--analysis-model` имеют приоритет. Параметр `OPENAI_ASK_QUESTION_PROB` и `/askprob` задают мягкую инициативность вопросов, а не измеренную частоту или запрет вопросов.

CometAPI поддерживает OpenAI-совместимый [Chat Completions](https://apidoc.cometapi.com/api/text/chat), но набор параметров зависит от модели. Для чата отправляется `reasoning_effort=medium`, для анализа — `high`. Выбирайте в настройках модели, которые поддерживают оба нужных значения через используемый маршрут CometAPI; например, [документация DeepSeek V4 Pro](https://www.cometapi.com/how-to-use-deepseek-v4-pro-api) отмечает, что `medium` может отображаться как `high`. Для моделей без поддержки reasoning запрос завершится явной ошибкой; автоматического переключения модели или бесконечных повторов нет. Проверяйте поддержку для конкретной модели и тарифа при развёртывании.

Чтобы не отправлять параметры, несовместимые с неизвестной моделью, запросы терапевта не задают `temperature`, штрафы и лимит токенов: действует лимит модели/API. Это может влиять на задержку и стоимость. Ответ с причиной завершения `length` продолжается ограниченное число раз; неполный или пустой ответ не сохраняется в историю как завершённый.

### 3. Данные (опционально, для RAG)

```bash
# XLSX -> dataset.json и три crowd-артефакта (для замены добавьте --force)
python src/convert_dataset.py --input path/to/dataset.xlsx

# PDF/TXT/DOCX из books/ -> чанки для RAG
python src/index_books.py

# Явное создание двух отдельных коллекций Qdrant
python scripts/rebuild_association_index.py
python scripts/rebuild_therapy_index.py
```

Актуальные источники: `data/dataset.json`, `association_index.json`,
`association_items.json`, `narrative_chunks.json` и `book_chunks.json`. Индекс
ассоциаций имеет формат `термин → данность → ID респондентов`; нарративы не
содержат ассоциаций. Коллекции `existential_associations` и
`existential_therapy` хранятся в `data/qdrant_storage/`. Обычный запуск бота
не переиндексирует их. Для намеренного пересоздания существующей коллекции
индексаторы требуют `--force`; при этом старая коллекция будет удалена.
`python setup.py` подготавливает файлы, но не создаёт векторные коллекции.
Данные, книги и локальное хранилище исключены из Git.

### 4. Запуск

```bash
# Telegram-бот
python run_telegram.py

# CLI-версия
python run.py
```

## Согласие перед началом

При первом обращении в личном чате бот показывает прежнее приветствие с коротким пояснением и кнопками «Да, давай начнём» / «Нет, пока не готов». До согласия разговорные функции и автоматические сообщения недоступны. Самое первое личное сообщение не передаётся ИИ: после принятия пользователь начинает беседу заново.

`/privacy` доступна и без согласия: присылает отдельный текст с описанием текущей обработки данных. Версия и время принятия сохраняются в существующем файле настроек, поэтому повторять выбор после перезапуска не нужно. При изменении смысла согласия обновите `CONSENT_VERSION` в `src/privacy.py` и версию в обоих текстах `consent_details` в `src/i18n.py`.

Это минимальный экран согласия, а не подтверждение полного соответствия 152-ФЗ. Он не меняет существующие хранение переписки, API и админ-инструменты и не требует новых реквизитов оператора в конфиге.

## Film-frame (`/shoot`)

Экспериментальная фича: бот собирает сцену по вашему состоянию и генерирует изображение.

В `.env`:

```env
FILM_FRAME_ENABLED=true
FILM_FRAME_ALLOWED_USER_IDS=123456789
FILM_FRAME_MODEL=seedream-5-0-pro-260628
FILM_FRAME_PER_USER_DAILY_LIMIT=2
FILM_FRAME_GLOBAL_DAILY_LIMIT=50
```

`FILM_FRAME_ALLOWED_USER_IDS` — пользователи, которые игнорируют дневные лимиты. Все остальные ограничены лимитами `FILM_FRAME_PER_USER_DAILY_LIMIT` и `FILM_FRAME_GLOBAL_DAILY_LIMIT`.

Сцену выбирает LLM по атмосфере сообщения: повседневная фотография остаётся
основой, выразительные кадры и мягкий магический реализм используются по
уместности. Пропорции 60/30/10 — ориентир в промпте, а не квоты или случайный выбор.

Для `seedream-5-0-pro-260628` запрос использует документированный CometAPI
параметр [`watermark: false`](https://www.cometapi.com/how-to-use-seedream-5-0-pro-api),
чтобы не добавлять видимую плашку. Бот не обрезает и не перекодирует ответ
провайдера и не удаляет метаданные происхождения; Telegram может обработать фото
при доставке. Для других настроенных моделей параметр не отправляется.

Подробности — в `.env.example`.
