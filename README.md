# Рой (Roi) — диалоговый ИИ для Telegram

Диалоговый ассистент для экзистенциальной терапии в традиции **Ирвина Ялома** и **Виктора Франкла**.
Помогает исследовать темы смысла, свободы, одиночества и конечности жизни.

> Диалоговый ассистент — не замена живому специалисту. Если вам тяжело или вы в кризисе — лучше, конечно, обратиться за профессиональной помощью.

## Возможности

* Диалог в духе экзистенциальной терапии. Мультимодальность по тексту, голосу и фото.
- RAG по книгам и датасету ассоциаций (Qdrant + sentence-transformers).
- Анализ ассоциаций (`/assoc`) и разбор ситуации (`/lysis`).
- Музыкальная библиотека (`/music`) и снимок на плёнку (`/shoot`).
- Русский и английский интерфейс, отзывы и админ-команды.

## Быстрый старт

### 1. Установка

```bash
git clone https://github.com/WhatAMistake/roi.git
cd roi

python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Конфигурация

```bash
# Windows
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

Заполните `.env` по примеру `.env.example`:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCdef...
OPENAI_API_KEY=your-api-key
OPENAI_API_BASE=https://api.cometapi.com/v1
USER_PREFS_ENCRYPTION_KEY=your-fernet-key
# Необязательно: числовой Telegram ID администратора
ADMIN_ID=123456789
```

Получите токен у [@BotFather](https://t.me/BotFather), а ключ Fernet
сгенерируйте командой:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Сохраните ключ в секрете и создайте резервную копию: без корректного ключа
согласие и настройки не сохраняются, а музыка недоступна. Существующие
зашифрованные данные нельзя восстановить без исходного ключа. `ADMIN_ID`
нужен для админ-функций; `0`их отключает.

В примере используется CometAPI через OpenAI-совместимый API. Для другого
совместимого API проверьте поддержку выбранных моделей и параметров.
Модель чата задаётся через `OPENAI_MODEL` (по умолчанию
`deepseek-v4.1-flash`); `OPENAI_ANALYSIS_MODEL` необязателен и при отсутствии
наследует основную модель. Явные `--model` и `--analysis-model` имеют
приоритет. Параметр `OPENAI_ASK_QUESTION_PROB` и `/askprob` задают мягкую
инициативность вопросов, а не измеренную частоту или запрет вопросов.

CometAPI поддерживает OpenAI-совместимый [Chat Completions](https://apidoc.cometapi.com/api/text/chat), но набор параметров зависит от модели. Для чата отправляется `reasoning_effort=medium`, для анализа — `high`. Выбирайте в настройках модели, которые поддерживают оба нужных значения через используемый маршрут CometAPI; например, [документация DeepSeek V4 Pro](https://www.cometapi.com/how-to-use-deepseek-v4-pro-api) отмечает, что `medium` может отображаться как `high`. Для моделей без поддержки reasoning запрос завершится явной ошибкой; автоматического переключения модели или бесконечных повторов нет. Проверяйте поддержку для конкретной модели и тарифа при развёртывании.

Чтобы не отправлять параметры, несовместимые с неизвестной моделью, запросы терапевта не задают `temperature`, штрафы и лимит токенов: действует лимит модели/API. Это может влиять на задержку и стоимость. Ответ с причиной завершения `length` продолжается ограниченное число раз; неполный или пустой ответ не сохраняется в историю как завершённый.

### 3. Данные (опционально, для RAG)

Запускайте команды из корня репозитория. Добавьте книги в `books/` и укажите
путь к XLSX с исходным датасетом:

```bash
# XLSX -> dataset.json и три crowd-артефакта (для замены добавьте --force)
python src/convert_dataset.py --input path/to/dataset.xlsx

# PDF/TXT/DOCX из books/ -> чанки для RAG
python src/index_books.py

# Явное создание двух отдельных коллекций Qdrant
python scripts/rebuild_association_index.py
python scripts/rebuild_therapy_index.py
```

Актуальные источники в `data/`: `dataset.json`, `association_index.json`,
`association_items.json`, `narrative_chunks.json` и `book_chunks.json`. Индекс
ассоциаций имеет формат `термин → данность → ID респондентов`; нарративы не
содержат ассоциаций. Для индекса ассоциаций нужен непустой
`association_items.json`, для терапевтического индекса — непустые
`narrative_chunks.json` и `book_chunks.json`.

Коллекции `existential_associations` и `existential_therapy` хранятся в
`data/qdrant_storage/`. Обычный запуск бота не переиндексирует их. Для
намеренного пересоздания существующей коллекции передайте соответствующему
скрипту `--force`; старая коллекция будет удалена. Конвертер тоже требует
`--force` для замены существующих артефактов; индексатор книг перезаписывает
`book_chunks.json`, если находит чанки. Модель эмбеддингов может загружаться
при первом использовании. Данные, книги и локальное хранилище исключены из Git.

### 4. Запуск

```bash
# Telegram-бот
python src/telegram_bot.py

# Интерактивная CLI-версия
python src/therapist_bot.py
```

Обе точки входа поддерживают `--model`, `--analysis-model` и `--no-rag`.
Например, для запуска без RAG: `python src/telegram_bot.py --no-rag`.
Скрипты в `old/` сохранены как старые версии и не являются актуальными
точками входа.

## Согласие перед началом

Бот работает в личном чате. При первом обращении он показывает приветствие с коротким пояснением и кнопками «Да, давай начнём» / «Нет, пока не готов». До согласия разговорные функции и автоматические сообщения недоступны. Самое первое личное сообщение не передаётся ИИ: после принятия пользователь начинает беседу заново.

`/privacy` доступна и без согласия: присылает отдельный текст с описанием текущей обработки данных. Версия и время принятия сохраняются в зашифрованном `data/user_prefs.json`, поэтому повторять выбор после перезапуска не нужно. При изменении смысла согласия обновите `CONSENT_VERSION` и оба текста `consent_details` в `src/i18n.py`.

Это минимальный экран согласия, а не подтверждение полного соответствия 152-ФЗ. Он не меняет существующие хранение переписки, API и админ-инструменты и не требует новых реквизитов оператора в конфиге.

|---------|----------|
| `/start` | Начать диалог |

| `/privacy` | Описание обработки данных |
| `/reset` | Сбросить историю |
| `/music` | Музыка по теме разговора |
| `/music off` / `/music on` | Выключить / включить автоматическую отправку музыки |

| `/lysis` | Глубокий разбор ситуации |
| `/shoot` | Снимок внутреннего состояния на плёнку |
| `/switchlang` | Переключить язык (ru/en) |
| `/lang ru` / `/lang en` | Выбрать язык явно |
| `/askprob 0.0–1.0` / `/askprob reset` | Настроить инициативность вопросов / вернуть значение по умолчанию |
| `/feedback ...` | Отзыв разработчику |
| `/void` | Взгляд в пустоту |
| `/silence` | Минута молчания |
| `/meaning` | Смысл момента |
| `/meaning_is` / `/meaning_gone` / `/meaning_where` | Управление регулярными сообщениями о смысле |
| `/remarque` | Замечание по недавнему диалогу |

Администратору также доступны `/admin`, `/stats`, `/updates. Про черновики обновлений и безопасную работу с
`data/code_hashes.json` см. [CONTRIBUTING.md](CONTRIBUTING.md#update-announcements).

Настройка музыкальной библиотеки и безопасное развёртывание: [docs/music.md](docs/music.md).
Аудиофайлы в репозиторий не входят. Для озвучивания по умолчанию используется
fable; экспериментальный голос по образцу и его ограничения описаны в
[docs/tts-clone.md](docs/tts-clone.md).

Также можно просто писать текстом, присылать фото или голосовые.

## Film-frame (`/shoot`)
Бот собирает сцену по вописанию вашего остояниюяи генерирует изображение. По умолчанию оыключена.

В `.env`:

```env
FILM_FRAME_ENABLED=true
FILM_FRAME_ALLOWED_USER_IDS=123456789
FILM_FRAME_MODEL=seedream-5-0-pro-260628
FILM_FRAME_PER_USER_DAILY_LIMIT=2
FILM_FRAME_GLOBAL_DAILY_LIMIT=50
```

`FILM_FRAME_ALLOWED_USER_IDS` — пользователи, которые игнорируют дневные лимиты; администратор также обходит их. Все остальные ограничены лимитами `FILM_FRAME_PER_USER_DAILY_LIMIT` и `FILM_FRAME_GLOBAL_DAILY_LIMIT`.

Сцену выбирает LLM по атмосфере сообщения: повседневная фотография остаётся
основой, выразительные кадры и мягкий магический реализм используются по
уместности. Пропорции 60/30/10 — ориентир в промпте, а не квоты или случайный выбор.

Для `seedream-5-0-pro-260628` запрос использует документированный CometAPI
параметр [`watermark: false`](https://www.cometapi.com/how-to-use-seedream-5-0-pro-api),
чтобы не добавлять видимую плашку. Бот не обрезает и не перекодирует ответ
провайдера и не удаляет метаданные происхождения; Telegram может обработать фото
при доставке. Для других настроенных моделей параметр не отправляется.

Подробности в `.env.example`.

```text

├── app/features/filmframe/   # /shoot
├── app/features/music/       # каталог, история и доставка музыки

├── books/                    # книги для индексации (PDF/TXT/DOCX не коммитятся)
├── certs/                    # локальные сертификаты (не коммитятся)

├── old/                      # старые скрипты запуска и настройки
├── prompts/                  # system prompt (ru/en)
├── scripts/                  # служебные скрипты (code cache и др.)
├── src/                      # ядро бота и RAG
│   ├── telegram_bot.py       # точка входа Telegram
│   ├── therapist_bot.py      # ядро диалога и точка входа CLI
│   ├── music.py              # совместимый импорт и проверка каталога
│   ├── privacy.py            # экран согласия
│   ├── rag.py
│   ├── i18n.py
│   ├── lang_utils.py
│   ├── code_reviewer.py
│   ├── convert_dataset.py
│   └── index_books.py
├── tests/                    # тесты
├── .env.example
└── requirements.txt
```

## Тесты

```bash
python -m pip install pytest
python -m pytest tests/
```

`pytest` не входит в `requirements.txt`. Для развёртывания из `main` в
репозитории также есть GitHub Actions workflow: он обновляет `/opt/roi` на
сервере и перезапускает `roi.service` через SSH.
